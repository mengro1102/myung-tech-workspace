# 외부에서 명테크 쓰기

폰이나 노트북에서, 집 밖에서도, 다른 나라에서도 명테크 화면을 열고 결재까지
하는 방법. **도메인을 사지 않고, 돈을 내지 않고** 한다.

---

## 먼저 알아야 할 것 — 이 서버에는 인증이 없다

명테크 API 는 로그인 없이 이런 일을 받는다.

- 결재 승인 → **유튜브 영상 업로드**, 파일 쓰기, 프로젝트 착수
- `POST /api/config/save` → **.env 저장**. GitHub 토큰·YouTube OAuth·텔레그램 봇 토큰
- 워크스페이스 파일 삭제, 태스크 큐에 지시 투입

이 PC 안에서만 쓰는 동안에는 `127.0.0.1` 바인드가 그 방어였다(`server.py` 의
`BIND_HOST`). 밖에 열면 그 방어가 사라진다. 그래서 **공유기 포트포워딩과
ngrok 무료 링크는 선택지가 아니다** — 주소만 알면 누구나 우리 유튜브 계정에
영상을 올릴 수 있게 된다.

접근 수단이 신원을 대신 세워 주거나, 앱에 열쇠를 달거나, 둘 중 하나다.

---

## 선택지 비교

| | Tailscale **serve** | Tailscale **funnel** | Cloudflare 임시 터널 | Cloudflare 정식 터널 |
|---|---|---|---|---|
| 비용 | 무료 | 무료 | 무료 | **도메인 구매 필요** |
| HTTPS | ✅ `*.ts.net` | ✅ `*.ts.net` | ✅ `*.trycloudflare.com` | ✅ |
| 도메인 구매 | 불필요 | 불필요 | 불필요 | 필요 |
| 주소 고정 | ✅ | ✅ | ❌ 켤 때마다 바뀜 | ✅ |
| 보는 기기에 앱 설치 | **필요** | 불필요 | 불필요 | 불필요 |
| 국내·국외 아무 네트워크 | ✅ | ✅ | ✅ | ✅ |
| 인증 | 네트워크가 대신 | 없음 → **열쇠 필수** | 없음 → 열쇠 필수 | Cloudflare 로그인 |

**도메인을 사야 하는 건 Cloudflare 정식 터널뿐이다.** Tailscale 은
`https://<기기이름>.<tailnet>.ts.net` 주소와 인증서를 무료로 발급해 준다.

---

## 결론

**두 겹으로 쓴다.**

1. **평소: `serve`** — 내 폰·노트북에서. 인터넷에 아무것도 노출되지 않고,
   비밀번호를 칠 일도 없다. 세계 어디서든, 어떤 네트워크든 된다.
2. **남의 PC를 써야 할 때만: `funnel`** — 같은 주소가 공개로 열린다. 앱 설치
   없이 아무 브라우저에서 열리고, **접근 열쇠 로그인 화면**이 먼저 뜬다.

`serve` 의 유일한 한계는 **보는 기기에 Tailscale 앱이 필요하다**는 것이다.
내 기기만 쓴다면 이건 한계가 아니다.

## 설치 (한 번만)

1. PC 에 https://tailscale.com/download/windows 설치 → **Gmail 계정으로 로그인**
2. 폰에도 Tailscale 앱 설치 → **같은 계정**
3. 관리 콘솔 → **DNS** → **MagicDNS** 와 **HTTPS Certificates** 켜기
   (이게 꺼져 있으면 `serve` 가 인증서를 못 만들어 실패한다)
4. PC 에서 `REMOTE.bat` 실행

끝. 폰에서 Tailscale 을 켜고 나온 주소를 열면 된다.

## 쓰는 법

```
REMOTE.bat            내 기기만 (기본)
REMOTE.bat funnel     아무 브라우저나 (열쇠 필요)
```

`REMOTE.bat` 이 하는 일: Tailscale 설치·로그인 확인 → 열쇠 확인 →
**빌드 신선도 확인 후 필요하면 재빌드** → 9000 포트 확인 → 공개 → 주소 출력.

멈추려면 `tailscale serve reset` (또는 `funnel reset`).

## 접근 열쇠

`.env` 의 `MYUNGTECH_ACCESS_KEY` 한 줄이다.

```
MYUNGTECH_ACCESS_KEY="긴-암호-문장"
```

- **비어 있으면** 예전과 똑같이 동작한다(무인증·루프백 전용).
- **값이 있으면** 터널을 타고 들어온 요청만 로그인 화면을 만난다. 이 PC 에서
  직접 부르는 요청(워치독·STATUS.bat·텔레그램 게이트웨이·로컬 브라우저)은
  그대로 통과한다 — 안 그러면 자동화가 전부 401 로 멈춘다.
- 판정 기준은 `X-Forwarded-For` 같은 프록시 흔적과 Host 이름이다. 터널은 반드시
  이 흔적을 남긴다.
- 로그인하면 30일짜리 HttpOnly 쿠키를 받는다. 폰에서 매번 치지 않아도 된다.
- 틀린 열쇠를 8번 넣으면 5분간 잠긴다.
- 바꾼 뒤에는 `RESTART.bat` — 서버가 기동할 때 한 번 읽는다.

`funnel` 은 열쇠가 없으면 `REMOTE.bat` 이 **실행을 거부한다.**

## 알아 둘 제약

- **PC 가 깨어 있어야 한다.** 절전으로 들어가면 어떤 방식이든 끊긴다.
  전원 옵션에서 절전을 "안 함" 으로 두는 편이 낫다.
- **9000 포트는 빌드본을 낸다.** 개발 서버(5174)가 아니다. UI 코드를 고쳤으면
  `npm run build` 가 필요한데, `REMOTE.bat` 이 알아서 검사하고 다시 빌드한다.
- **Tailscale 무료 Personal 플랜은 "비상업적 용도" 기준이다.** 1인 기업의 내부
  관리 화면은 경계선에 있다. Gmail 계정으로 가입하면 자동으로 Personal 로
  들어가고, 회사 도메인 메일로 가입하면 업무용으로 분류된다. 나중에 사람이
  늘거나 고객에게 무언가를 보여 주게 되면 유료 플랜을 봐야 한다.
- **funnel 은 공개 포트가 443·8443·10000 으로 제한**되고 대역폭 상한이 있다
  (수치는 공개되지 않음). 우리는 443 → 로컬 9000 으로 매핑한다.
- 일부 국가·망에서는 Tailscale 자체가 막힐 수 있다. 그 경우엔 `funnel` 주소가
  대안이 된다(공개 HTTPS 라 일반 웹 트래픽과 같다).

## 이것 말고 이미 되는 것

**텔레그램 봇이 결재는 이미 폰에서 처리한다.** `/결재` 로 목록을 받고 버튼으로
승인·거절한다. 밖에서 급한 일은 대개 결재라, 터널 없이도 그 부분은 된다.
자세한 건 관리 탭 → 연동 → 텔레그램 카드의 안내를 볼 것.
